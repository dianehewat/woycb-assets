# Production Evidence

This folder contains evidence that **What Only You Can Bring™** is operating as a live AI-native Human Potential Recognition™ system using **Google Gemini 2.5 Pro**.

The evidence traces the working system from participant story submission through AI reasoning, reflection generation and delivery, to real participant feedback and pilot validation.

## Evidence

1. **Make.com Production Workflow Execution**  
   Live production workflow and successful execution history.

2. **Gemini 2.5 Pro Production Configuration**  
   Production configuration showing Gemini 2.5 Pro within the live workflow.

3. **Google Cloud Gemini API Billing Evidence**  
   Google Cloud evidence of real Gemini API usage and associated cost.

4. **Demonstration Human Potential Reflection™**  
   A demonstration output generated using an indicative story, showing the participant-facing reflection produced by the system.

5. **Live Tally Participant Story Intake**  
   The live participant experience used to collect a story for Human Potential Recognition™.

6. **Tally Participant Feedback Form**  
   The live feedback experience used to evaluate participant response to the reflection.

7. **Automated Reflection Email Delivery**  
   Evidence of the automated participant delivery experience, including the generated Human Potential Reflection™.

8. **Real User Testimonials**  
   Permissioned testimonials from real pilot participants describing their experience and perceived value.

9. **Real Pilot Feedback Evidence**  
   Analysis of 12 real pilot feedback responses, including quantitative results, qualitative evidence, product learning and relevance to Education & Human Potential.

10. **Anonymised Pilot Feedback Data**  
    Anonymised response-level data supporting the pilot feedback analysis, with participant names, email addresses and platform identifiers removed.

## Evidence Chain

**Real participant story → Live automated workflow → Gemini 2.5 Pro reasoning → Human Potential Reflection™ → Automated delivery → Participant feedback → Pilot evidence**

Together, these artefacts demonstrate a functioning end-to-end system and provide evidence of real-world participant use, response and learning.

## Privacy

All public production evidence has been reviewed to protect participant privacy and exclude credentials, API keys, private resource identifiers and other sensitive information.
